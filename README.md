# Рейтинг игроков Аист-4

Программа раз в сутки забирает с rfll.ru календарь команды и протоколы матчей, считает баллы игроков
и обновляет страницу рейтинга. Работает бесплатно на GitHub, компьютер включать не нужно.

## Установка (один раз, около 30 минут)

1. Зарегистрируйтесь на https://github.com.
2. Нажмите «New repository». Имя: `aist4-rating`, тип: Public. Нажмите «Create repository».
3. Нажмите «uploading an existing file» и перетащите в окно все файлы и папки из архива.
   Папка `.github` скрытая: если она не загрузилась, создайте файл вручную через
   «Add file → Create new file», имя `.github/workflows/update.yml`, и вставьте текст
   из одноименного файла архива.
4. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/docs` → Save.
5. Settings → Actions → General → Workflow permissions: «Read and write permissions» → Save.
6. Вкладка Actions → «Обновление рейтинга» → «Run workflow».
   Через 1-2 минуты страница откроется по адресу `https://ВАШ_ЛОГИН.github.io/aist4-rating/`.

Дальше обновление идет само каждый день в 08:00 по Москве.
Запустить вручную можно той же кнопкой «Run workflow».

## Лучший игрок матча

Пока бот ВКонтакте не подключен, итог опроса вносится в файл `data/mvp.csv`
(на GitHub: открыть файл, значок карандаша, «Commit changes»). Одна строка на матч:

```
match_id,player
39158,Овсянников
```

`match_id` это число из адреса протокола (rfll.ru/match/39158), `player` это фамилия
как в протоколе или номер игрока с rfll.ru.

## Матчи Кубка

Страница команды без параметров показывает только текущий турнир (сейчас Чемпионат),
а страницы с параметрами правила сайта закрывают для программ. Поэтому номера кубковых
матчей вносятся в `data/cup_matches.csv`, по одному на строку:

```
match_id
39201
```

Номер берется из адреса протокола. Все остальное (счет, составы, соперник) программа
заберет сама. Матчи Чемпионата, попавшие в список один раз, сохраняются в
`data/our_matches.json` и не пропадут, даже когда на странице команды сменится турнир.

## Настройки

Все веса баллов, названия турниров и параметры вратаря находятся в `config.yaml`.
Код менять не нужно.

## Если что-то не так

Откройте Actions → последний запуск → шаг `python main.py`. Строки «ВНИМАНИЕ» объясняют,
что не получилось. Если сайт лиги изменит верстку, какие-то данные перестанут распознаваться:
пришлите эти строки, и парсер подстроим.

# Бот ВКонтакте

Бот запускается каждый час вместе с рейтингом. Он читает афиши на стене лиги, просит капитана
подтвердить найденный матч, публикует опрос о явке, после матча выкладывает сводку и опрос о лучшем
игроке, подсчитывает голоса по правилам команды и раз в месяц публикует итоги месяца.

От имени сообщества (club241645516) приходят сводки, итоги и личные вопросы капитану и помощникам.
От имени технического аккаунта публикуются опросы.

## Шаг 1. Ключ сообщества

1. Сообщество → Управление → Работа с API → Ключи доступа → «Создать ключ».
2. Отметьте «Разрешить приложению доступ к сообщениям сообщества». Остальное не нужно.
3. Подтвердите кодом и скопируйте ключ (длинная строка). Никому его не пересылайте.

## Шаг 2. Ключ технического аккаунта

1. В окне браузера, где выполнен вход в технический аккаунт (не в ваш личный!), откройте адрес:
   `https://oauth.vk.com/authorize?client_id=6121396&scope=wall,messages,offline&redirect_uri=https://oauth.vk.com/blank.html&display=page&response_type=token&revoke=1`
2. Нажмите «Разрешить». Откроется пустая страница с предупреждением; ничего на ней не вводите.
3. В адресной строке найдите фрагмент `access_token=` и скопируйте все, что идет после него до знака `&`.
   Это ключ. Он дает полный доступ к техническому аккаунту, поэтому хранится только в секретах GitHub.

## Шаг 3. Секреты в GitHub

Репозиторий → Settings → Secrets and variables → Actions → «New repository secret». Создайте два:

- `VK_GROUP_TOKEN`: ключ сообщества;
- `VK_USER_TOKEN`: ключ технического аккаунта.

## Шаг 4. Проверка ключей и номера беседы

1. Actions → «Обновление рейтинга» → «Run workflow», в поле «Режим запуска» выберите «проверка ключей».
2. В журнале шага «Бот и рейтинг» будут строки «Ключ ... работает» и два списка бесед с номерами.
3. Откройте `config.yaml` (значок карандаша) и в разделе `bot` впишите:
   `chat_peer_group`: номер беседы команды из списка сообщества,
   `chat_peer_user`: номер той же беседы из списка технического аккаунта (номера разные, это нормально).

## Шаг 5. Пробный запуск

Actions → «Run workflow», режим «пробный». Бот ничего не отправит и не сохранит, а в журнале покажет,
что сделал бы. Если там нет ошибок, дальше все работает само, раз в час.

## Если ключ технического аккаунта перестал работать

Бот напишет капитану, что ключ недействителен. Повторите шаг 2 и замените секрет `VK_USER_TOKEN`
(Settings → Secrets and variables → Actions → карандаш у секрета).

## Сопоставление страниц ВК с игроками

Голос за самого себя не засчитывается. Страницы ВК сопоставляются с игроками по имени и фамилии.
Если бот не узнал игрока, он пришлет капитану список таких страниц; впишите их в `data/vk_players.csv`:

```
vk,player
https://vk.ru/id12345,Демидов Данила
```
